# Yemen Commerce Flutter Client

This Flutter foundation is intentionally mobile-first and Arabic-first. It mirrors the server and web application's versioned `v1` marketplace vocabulary, keeps layout direction RTL by default, and does not duplicate authorization, pricing, payment, cart, or order rules that the server must enforce.

The initial source contains the contract mirror, a market-aware shell, and safe capability states. It is kept in the same repository so future mobile increments are reviewed and versioned with the backend and responsive web client.
